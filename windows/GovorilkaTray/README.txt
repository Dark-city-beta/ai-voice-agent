GovorilkaTray.exe

Windows tray remote control for Hermes Govorilka on the local Ubuntu server.
This version opens a small visible window with buttons on launch.

Default server:
  http://192.168.31.200:8766

Hotkeys:
  Ctrl+Alt+G  start/stop Govorilka
  Ctrl+Alt+M  mute/unmute microphone
  Ctrl+Alt+S  mute/unmute speakers

Tray:
  Double click icon: open window
  Right click icon: menu
  Minimize or close window: hide to tray

To change the server URL, edit config.json in the same folder.
